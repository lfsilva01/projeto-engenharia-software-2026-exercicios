# Declaração de Escopo - <Sistema de Gestão da biblioteca>

**Versão:** 1.0
**Data:** 02/09/2026
**Aprovada por:** A definir

## Inclusões

| # | Item |
| --- | --- |
| I1 | Desenvolvimento do sistema para cadastro e gerenciamento do acervo da biblioteca. |
| I2 | Cadastro dos estudantes atendidos pela biblioteca e seus dados necessários para os empréstimos. |
| I3 | Registro de empréstimos, devoluções e controle da situação das obras. |
| I4 | Geração de relatórios de obras com devolução em atraso. |
| I5 | Implantação de backup automatizado da base de dados. |
| I6 | Migração dos 12.000 títulos cadastrados no sistema antigo para o novo sistema. |
| I7 | Etiquetagem física dos exemplares para utilização no novo sistema. | 
| I8 | Treinamento das 3 servidoras e elaboração da documentação básica para utilização do sistema. |

## Exclusões

| # | Item | Observação |
| --- | --- | --- |
| E1 | Manutenção do sistema no ano seguinte à entrega | O projeto contempla a entrega e implantação inicial do sistema. A manutenção após esse período deverá ser tratada separadamente. |
| E2 | Contratação de uma quarta servidora | A contratação de novos funcionários é uma decisão administrativa da instituição e não faz parte do projeto de desenvolvimento do sistema. |
| E3 | Compra ou substituição de computadores e equipamentos de infraestrutura | O projeto considera que a infraestrutura necessária para utilizar o sistema será disponibilizada pela instituição. Caso seja necessário adquirir novos equipamentos, isso será responsabilidade do campus. |
| E4 | Desenvolvimento de aplicativo para celular | O projeto tem como objetivo desenvolver o sistema de gestão da biblioteca, não incluindo uma versão específica para dispositivos móveis. |
| E5 | Recadastramento manual dos 12.000 títulos caso os dados do sistema antigo não possam ser acessados | Recadastramento manual dos 12.000 títulos caso os dados do sistema antigo não possam ser acessados |

## Entregas
