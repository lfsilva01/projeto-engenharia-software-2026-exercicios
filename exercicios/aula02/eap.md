# C2 – Dicionário dos Pacotes de Trabalho

## Critérios de escolha dos pacotes

- **Maior estimativa:** 1.8.3 – Etiquetagem física dos exemplares (64h).
- **Menor estimativa:** 1.1.3 – Gestão dos riscos do projeto (16h).
- **Pacote que não é software:** 1.9.1 – Treinamento das 3 servidoras.
- **Pacote mais arriscado:** 1.8.1 – Migração dos dados disponíveis do sistema antigo.

---

## 1.8.3 – Etiquetagem física dos exemplares

**Critério de escolha:** Foi escolhido por ser o pacote com a maior estimativa da EAP, totalizando **64 horas**.

| Campo | Conteúdo |
|---|---|
| **Descrição** | Realizar a etiquetagem dos exemplares da biblioteca para que possam ser identificados e utilizados corretamente no novo sistema. |
| **Entrega** | Exemplares etiquetados e preparados para utilização no sistema. |
| **Responsável** | Equipe do projeto, com o apoio das servidoras da biblioteca. |
| **Estimativa** | 64 horas. |
| **Predecessor** | 1.8.1 – Migração dos dados disponíveis do sistema antigo. |
| **Critério de conclusão** | Os exemplares previstos devem estar etiquetados e ser identificados corretamente durante os testes no sistema. |
| **Premissas** | Os exemplares estarão disponíveis para a etiquetagem e o novo sistema utilizará códigos para identificá-los. |
| **Exclui** | A organização geral do acervo e os serviços de conservação ou reparo dos livros. |

---

## 1.1.3 – Gestão dos riscos do projeto

**Critério de escolha:** Foi escolhido por possuir uma das menores estimativas da EAP, com **16 horas**.

| Campo | Conteúdo |
|---|---|
| **Descrição** | Identificar os possíveis riscos do projeto e definir formas de evitar ou reduzir seus impactos. |
| **Entrega** | Registro dos principais riscos identificados e das ações previstas para cada um. |
| **Responsável** | Gerente do projeto. |
| **Estimativa** | 16 horas. |
| **Predecessor** | 1.1.1 – Plano de projeto. |
| **Critério de conclusão** | Os principais riscos devem estar identificados, registrados e acompanhados durante o projeto. |
| **Premissas** | As pessoas envolvidas no projeto fornecerão as informações necessárias para identificar possíveis riscos. |
| **Exclui** | A garantia de que todos os riscos serão eliminados ou a solução de problemas que não estejam relacionados ao projeto. |

---

## 1.9.1 – Treinamento das 3 servidoras

**Critério de escolha:** Foi escolhido por ser um pacote que não envolve o desenvolvimento de software.

| Campo | Conteúdo |
|---|---|
| **Descrição** | Treinar as três servidoras da biblioteca para que possam utilizar as principais funcionalidades do novo sistema. |
| **Entrega** | Três servidoras treinadas para utilizar o sistema. |
| **Responsável** | Equipe do projeto ou responsável pelo treinamento. |
| **Estimativa** | 16 horas. |
| **Predecessor** | 1.8.4 – Implantação do sistema no ambiente da biblioteca. |
| **Critério de conclusão** | As três servidoras devem participar do treinamento e conseguir realizar as principais atividades no sistema durante uma atividade prática. |
| **Premissas** | As três servidoras estarão disponíveis nos horários definidos para o treinamento. |
| **Exclui** | O treinamento de novos funcionários contratados após a conclusão do projeto. |

---

## 1.8.1 – Migração dos dados disponíveis do sistema antigo

**Critério de escolha:** Foi escolhido por ser considerado o pacote mais arriscado, já que o sistema atual é antigo, funciona em apenas uma máquina e não possui mais suporte do fornecedor.

| Campo | Conteúdo |
|---|---|
| **Descrição** | Transferir para o novo sistema os dados que estiverem disponíveis e puderem ser acessados no sistema antigo da biblioteca. |
| **Entrega** | Dados disponíveis do sistema antigo migrados para o novo sistema. |
| **Responsável** | Equipe responsável pela migração dos dados. |
| **Estimativa** | 40 horas. |
| **Predecessor** | 1.3.2 – Modelagem da base de dados. |
| **Critério de conclusão** | Os dados disponíveis devem ser migrados para o novo sistema e conferidos para garantir que foram transferidos corretamente. |
| **Premissas** | Será possível acessar e recuperar os dados existentes no sistema antigo. |
| **Exclui** | O recadastramento manual dos títulos caso os dados do sistema antigo não possam ser recuperados. |
